# Interactive Visualizations: Psychiatric and Substance Use Disorder Multimorbidity

This repository contains interactive visualizations accompanying the manuscript:

**Pathways of Psychiatric Multimorbidity Surrounding First Substance Use Disorder Diagnosis in Youth**

*Clarissa Janousch, Andreas Lundin, Mathias Mattsson, Peter Wennberg, Sara Wallhed Finn, Anna-Karin Danielsson*

*Submitted to JAMA Psychiatry*

The interactive visualizations provide additional detail for the analyses presented in the manuscript and allow users to explore results across diagnostic categories, time periods, and other analysis-specific selections.


### Main Analyses

Interactive Alluvial Plot (diagnostic trajectories)

Interactive UpSet Plot (intersections of co-occurring disorders)

Interactive Regression Results (regression results of trajectories and intersections)

### Sensitivity Analyses

Recreation of the same interactive graphs but excluding all individuals with an acute alcohol-related diagnosis (ICD-10 F10.0), who appeared exclusively in the most common trajectory: No visit -> 1 SUD -> No visit -> No visit.

Interactive Alluvial Plot (diagnostic trajectories)

Interactive UpSet Plot (intersections of co-occurring disorders)

Interactive Regression Results (regression results of trajectories and intersections)


### About the Interactive Visualizations

The visualizations are hosted using GitHub Pages. 

The repository contains the HTML files and associated resources required to display the interactive visualizations. No individual-level study data are included in this repository.
